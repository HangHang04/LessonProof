## 本次改进

| Before | After | Why |
| --- | --- | --- |
| 切换标签会重置勾选和复核文字 | 同课程、同版本、同阶段保留输入和展开内容，阶段变化后重新确认 | 避免重复填写，让审批对应当前操作 |
| 页面离开后，较慢的请求可能覆盖新页面 | 按当前页面和课程核对异步返回 | 尊重用户主动导航 |
| 小字与较窄按钮，手机操作位于长讲义后 | 阅读字号提高，按钮至少 44 px 高，手机先显示下一步 | 降低阅读和操作负担 |
| 选文件前缺少格式提示 | 原生对话框说明材料、大小与格式入口，缺材料可重新导入 | 提供可行动的指导 |
| 动效缺少按下反馈，减少动效仍有旋转 | 120 ms 按下反馈、200 ms 对话框进入，减少动效时关闭动画 | 反馈清楚，兼顾可访问性 |

异常审阅同时提供类名、消息和完整报错文本，避免把独立字段误读为缺失信息。无效模型回复最多纠正一次，每次请求、响应与错误均保留；最终仍无效时不进入审核。文件读取按实际大小分配，保留 8 MiB 上限和读取期间变化检查。

## 复现

基础检查：

```powershell
python -m unittest -v
node test_web.cjs
node --check web/app.js
node --check verify_browser.js
python demo.py
python verify_sandbox.py
```

三课程后台集成可另运行 `python verify_workflow.py`。浏览器完整流程需先启动工作台与本地模型，再运行：

```powershell
.\start.ps1 -NoBrowser
npx --yes --package @playwright/cli playwright-cli --session lessonproof open http://127.0.0.1:8765
npx --yes --package @playwright/cli playwright-cli --session lessonproof run-code --filename verify_browser.js
```

最后一个入口真实调用模型和隔离器、创建三份课程及交付记录，并在 `output/playwright/` 保存下载包和截图。它用于开发回归，耗时取决于来源网络、设备与模型加载。
